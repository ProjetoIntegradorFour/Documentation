### Organização no GitHub

- [✓] **Board atualizado no GitHub Projects**
  - Backlog organizado (tarefas futuras)
  - Sprint atual configurada (coluna *To Do* com Issues priorizadas)
  - Tarefas em andamento e concluídas movidas corretamente
- [✓] **Issues criadas e detalhadas**
  - Título objetivo  
  - Descrição clara + critérios de aceitação  
  - Labels aplicadas (`feature`, `bug`, `doc`, `alta prioridade`, etc.)  
  - Milestone vinculada à sprint correspondente  
  - Responsável definido  
  - Rastreabilidade → vincular PRs, documentação ou outras Issues dependentes  
  - Esforço estimado: P / M / G

---

### Desenvolvimento

- [✓] **Branches criadas** por funcionalidade  
- [✓] **Pull Requests (PRs)** abertos, vinculados às Issues  
- [✓] **Code Review** realizado por pelo menos 1 colega  
- [✓] **Padrão de commits seguido**
  - Mensagens claras e consistentes  
  - Ex.: `feat/login: implementar tela de login`
- [  ] **Definition of Done (DoD) cumprido**
  - Código implementado  
  - PR revisado e aprovado  
  - Testes executados (manuais ou automatizados)  
  - Documentação atualizada
