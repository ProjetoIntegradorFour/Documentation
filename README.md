# Documentation

Repositório dedicado à documentação do projeto **Sistema de Gerenciamento de Biblioteca**.  
Aqui estão armazenados todos os documentos relacionados ao planejamento, acompanhamento e relatórios de sprint da equipe.

---

## Estrutura do Repositório

```
Documentation
├─ Anexo 1 - Termo de abertura.pdf
├─ ChecklistQuinzenal.md
├─ Fluxograma biblioteca.pdf
├─ README.md
├─ relatorios
│  ├─ img/
│  └─ sprints.md [...]
└─ Sistema_Gerenciamento_de_Biblioteca.pdf
```

---

## Descrição dos Arquivos

### **Sistema_Gerenciamento_de_Biblioteca.pdf**
Documento principal do projeto, contendo o **documento de visão**: objetivos, escopo, requisitos iniciais e principais funcionalidades.

### **Anexo 1 - Termo de abertura.pdf**
Formalização do início do projeto, descrevendo o propósito, responsáveis e autorização para execução.

### **ChecklistQuinzenal.md**
Checklist de acompanhamento utilizado a cada sprint.  
Contém critérios para:
- Organização no GitHub (Boards, Issues, PRs, etc.)
- Indicadores e métricas de progresso
- Estrutura esperada dos relatórios quinzenais

*(Os itens de desenvolvimento e indicadores são detalhados em cada `relatorios/sprintX.md`.)*

### **Fluxograma biblioteca.pdf**
Fluxograma representando o **fluxo de uso do sistema**, desde o cadastro de usuários até o empréstimo e devolução de livros.

---

## Pasta `/relatorios`

Contém os **relatórios quinzenais** de cada sprint, com:
- Objetivo da sprint  
- Entregas concluídas  
- Indicadores e métricas  
- Dificuldades e aprendizados  
- Rastreamento entre Issues, PRs e entregas  

Exemplo:
```
relatorios/
├─ sprint1.md
├─ sprint2.md
├─ sprint3.md
└─ img/
   ├─ indicador.jpg
   ├─ indicador1.jpg
   ├─ indicador2.jpg
```

Cada relatório segue o modelo definido no *Checklist Quinzenal*.
